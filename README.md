# 图标预审 Web

手机优先的本地图标预审工具。无需安装依赖，图片不会上传服务器。

## 当前规则

- 真实 PNG 文件签名
- JPG、JPEG、WebP、GIF 等浏览器支持的图片也可显示预览，但文件格式判定不通过
- 画布必须为 200 × 200 px
- 文件大小不超过 15 KB
- 存在 Alpha 通道和真实透明像素
- 可见内容不得超出居中的 190 × 190 px 制图区
- 可见内容位于 190 × 190 px 制图区内即通过
- 粘贴图片不判定文件大小，需选择下载后的原始 PNG 才能准确核验
- 支持通过系统分享面板分享工具链接，不支持时复制链接

## 本地预览

```bash
python3 server.py
```

在浏览器中打开 `http://127.0.0.1:8080/`，健康检查为 `http://127.0.0.1:8080/healthcheck`。

## 行云运行

项目根目录已经提供 `Dockerfile`。容器监听 `0.0.0.0:8080`，只暴露一个端口，无环境变量或外部服务依赖。

剪贴板主动读取需要安全来源（HTTPS 或 localhost）及浏览器授权。移动浏览器不支持时，可以使用系统粘贴动作或“选择原始 PNG”。

分享工具链接需要通过 HTTPS 部署；本地 `file://` 和 localhost 地址只显示部署提示，不调用系统分享，不能分享给其他人使用。
